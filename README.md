# FEDISVM

Native virtual machine manager for Apple Silicon Macs running macOS 14 or later.

Download **FedisVM-Mac-M-chip.dmg** from [Releases](https://github.com/FedisX/FedisVM/releases).
This repository contains public downloads and authenticated update metadata. Application source is maintained in a separate private repository.

Windows requires an ARM64 guest image and its own license. Ubuntu and other supported Linux distributions use ARM64 media.

This initial build uses ad-hoc macOS code signing and is not Apple-notarized. Update authenticity is verified separately using a pinned Ed25519 publisher key and archive SHA-256.
